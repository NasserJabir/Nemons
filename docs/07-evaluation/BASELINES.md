# Baselines

## Purpose
Separate value created by Nemons from value already available through a Coding Agent harness or a concise manual handoff.

## Proposed comparisons
- **B0 — Native harness:** same task without Nemons-managed continuity.
- **B1 — Manual handoff:** concise human-prepared handoff with task state and decisions.
- **N1 — Nemons handoff/context:** generated handoff and curated Context Pack.
- **N2 — Governed retrieval:** N1 plus category-conditioned admission, freshness checks, and provenance-aware retrieval.

Use only comparisons that answer the experiment. Do not vary models/harness versions without recording confounds.

## Controls
Pin task fixtures, repository, environment, model/harness versions, and acceptance criteria. Randomize run order where practical. Separate proposal and evaluation examples where feasible. Record exclusions and missing telemetry. Compare quality and overhead together, including negative governance/security cases.

## Status
Proposed; no performance claims until measured.
