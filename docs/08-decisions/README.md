ADRs capture decisions, context, consequences, and status. A decision is not accepted merely because it appears in research or a proposal.

## Decision discipline

Each new ADR should state status, problem, options considered, decision, rationale/evidence, consequences, risks, and validation plan. Distinguish accepted invariants from proposals and open questions. Governance authority, numerical admission thresholds, adapter choices, storage technology, and queue/concurrency decisions remain open until explicitly resolved.
