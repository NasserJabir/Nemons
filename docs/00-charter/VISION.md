# Vision

## Vision statement

Make agent work continuous across Coding Agents without making knowledge opaque, unreviewable, or silently mutable.

Nemons should let a team resume work with the relevant state, operational persona, skills, tools, evidence, and verified knowledge available through portable contracts rather than relying on one harness's private session format.

## Intended outcomes

- Less repeated discovery after a session or agent switch.
- Better traceability from decisions and reusable assets to sources and execution evidence.
- Task-adaptive context that is relevant, bounded, and explicit about uncertainty.
- Safe, reviewable evolution of operational assets.
- Comparable evaluation across harnesses and adapters.

## Principles

1. Portability before harness-specific convenience.
2. Explicit state before implicit conversational assumptions.
3. Evidence and provenance before trust.
4. Reviewable asset evolution before autonomous adoption.
5. Measured value before architectural complexity.
6. Fail closed for protected actions and governance boundaries.

## Success is not

More tokens in context, more generated skills, more autonomous actions, or more subagents by themselves. Success means a measurable improvement in correct, reproducible, governable task completion after accounting for latency, cost, and operational complexity.
